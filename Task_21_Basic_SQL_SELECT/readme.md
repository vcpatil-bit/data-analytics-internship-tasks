# Task 21 – Basic SQL SELECT

## Project Overview

This task demonstrates the use of basic SQL commands for data analysis using MySQL Workbench and the MySQL `world` database.

The analysis focuses on retrieving, filtering, sorting, and limiting data using SQL.

## Tools Used

- MySQL Server 8.0
- MySQL Workbench
- SQL
- World Database

## Objectives

1. Retrieve data using SELECT.
2. Select specific columns from a table.
3. Filter records using WHERE.
4. Sort records using ORDER BY.
5. Use ASC and DESC sorting.
6. Limit the number of returned records.
7. Combine filtering and sorting conditions.

## Tables Used

### city
Contains information about cities, including:
- Name
- CountryCode
- Population

### country
Contains information about countries, including:
- Name

- Population
