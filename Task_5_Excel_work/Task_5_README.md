# Task 5 — Excel Data Analysis

## Internship
VEDA Technology — Level 1

## Objective
Analyze the Sample Superstore dataset in Microsoft Excel using formulas, KPIs, PivotTable-style summaries, charts, and business insights.

## Dataset
- **Source file:** Sample Superstore
- **Records:** 10,194
- **Unique Orders:** 5,111
- **Date Range:** 03-Jan-2023 to 30-Dec-2026

## Workbook Structure
The final workbook contains:

1. **Raw_Data** — original dataset, kept as the raw-data layer.
2. **Working** — calculations and derived fields.
3. **Summary** — KPIs, formula examples, findings, and business summary.
4. **Pivot_Category** — sales/profit analysis by category.
5. **Pivot_Region** — sales/profit analysis by region.
6. **Pivot_Month** — monthly sales/profit trend.
7. **Pivot_SubCategory** — sub-category performance.
8. **Pivot_Segment** — segment performance.

## Key Findings
- **Top Category by Sales:** Technology
- **Top Region by Sales:** West
- **Top Sub-Category by Sales:** Chairs
- **Top Sub-Category by Profit:** Copiers
- Monthly analysis is available in the `Pivot_Month` sheet.
