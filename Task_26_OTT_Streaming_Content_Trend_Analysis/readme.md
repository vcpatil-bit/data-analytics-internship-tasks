# OTT Streaming Content Trend Analysis

## Project Overview

This project analyzes an OTT streaming content catalog using Python, SQL, and data visualization techniques.

The objective is to identify trends in Movies and TV Shows, genres, release years, countries, ratings, and content additions.

## Objectives

- Analyze the distribution of Movies and TV Shows
- Identify major content genres
- Analyze release-year trends
- Examine content additions over time
- Identify major content-producing countries
- Analyze content ratings
- Generate business-oriented insights

## Dataset

The project uses the Netflix Movies and TV Shows dataset.

### Main Columns

- show_id
- type
- title
- director
- cast
- country
- date_added
- release_year
- rating
- duration
- listed_in
- description
