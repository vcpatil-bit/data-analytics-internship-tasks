
# E-Commerce Customer Segmentation Using RFM Analysis

## Project Overview
This project analyzes online retail transactions and segments
customers based on Recency, Frequency, and Monetary value.

## Objectives
- Explore and clean transaction data
- Calculate customer-level RFM metrics
- Assign RFM scores and customer segments
- Visualize customer distribution and revenue
- Recommend targeted marketing strategies

## Tools and Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn,
Scikit-learn, Jupyter Notebook

## Methodology
1. Data exploration
2. Data cleaning and preprocessing
3. RFM feature engineering
4. RFM scoring
5. Customer segmentation
6. Visualization
7. Marketing recommendations

## Outputs
- Customer-level RFM metrics and scores
- Customer segment summaries
- Revenue summary by segment
- Customer segmentation charts
- Marketing campaign recommendations
- Project report

## Dataset
UCI Online Retail:
https://archive.ics.uci.edu/dataset/352/online+retail

Download the dataset and place the Excel file in the data folder
before running the notebook.

## How to Run
Install dependencies:
pip install -r requirements.txt

Open the notebook in Jupyter and run the cells in order.

## Business Value
RFM analysis helps identify high-value customers, customers
needing retention campaigns, and opportunities to encourage
repeat purchases.

## Limitations
RFM is descriptive and does not prove campaign effectiveness.
Marketing recommendations should be validated using suitable
experiments and business KPIs.
