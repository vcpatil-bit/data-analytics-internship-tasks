# Task 16 – Simple Profit Analysis
## Objective

Compare total and average profit across product categories using the Sample Superstore dataset.

## Tools Used

- Microsoft Excel

## Analysis Performed

- Category-wise total profit
- Average profit
- Record count
- Profit margin
- Profit comparison chart

## Key Findings

- Technology generated the highest total profit.
- Office Supplies generated the second-highest total profit.
- Furniture generated substantially lower total profit.
- Profit margin provides additional insight beyond total sales.

## Dataset

Sample Superstore dataset.

## Deliverables

- Excel analysis workbook
- Profit comparison chart
- Analysis report
